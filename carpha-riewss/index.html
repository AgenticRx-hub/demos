Data sources and assumptions

Order of evidence used in this demo

  • CARPHA's own information: ToR RG-T4387 scope, deliverables, reporting obligations, evaluation criteria and Member State list.
  • Real-world public data: approximate Member State populations (rounded public estimates, 2024-2025).
  • Sample data: none was available from CARPHA, so weekly case counts are generated.
  • Predicted data: completeness, timeliness and readiness per Member State are modelled estimates, not measurements.

Assumptions

  • Weekly syndromic counts scale with population (ILI about 9 per 10,000 per week; gastroenteritis 6; fever and rash 2; SARI 0.8), with seasonality and random noise.
  • Six outbreak events are seeded across the year (1.4x to 1.9x baseline for 2 to 4 weeks) so detection can be measured.
  • Reported counts = true counts x completeness. Lower completeness hides part of each outbreak.
  • Instance configuration: 3 consultant days per Member State; training days as set by the slider.
  • Each false alarm takes about half a day of a national epidemiologist's time to verify.
