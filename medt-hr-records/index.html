AI Records Assistant

Ask a question in plain English. Every answer cites the file, document and page it came from, and respects the user's SharePoint permissions. In production this would run only inside the Ministry's Microsoft 365 tenant, with the Ministry's written approval. This demonstration runs entirely in your browser on sample data.

How it works

  1. Index. OCR text and metadata of every uploaded page is indexed with its National ID, document type and date.
  2. Understand. The question is parsed for people, IDs, schools, document types, dates and counts.
  3. Retrieve. Only records the user is allowed to see are searched.
  4. Answer with sources. The answer links to the exact file, document and page, so HR can check it.

Guardrails

  • Restricted documents (medical, disciplinary) are never summarised for users without access
  • No data leaves the Ministry tenant
  • Every query is logged for audit
  • Answers without a source are not shown
