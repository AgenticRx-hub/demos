Clickable app prototype (iOS, Android and mobile web from one codebase)

Try these journeys on the phone, which works with a mouse or touch:

  1. Start from "What do you need today?": six plain-language doors, no program names.
  2. I want training: filter by field and location, save, and check eligibility.
  3. Open the Healthcare Hiring Fair: register, add to calendar, get a text reminder.
  4. I need career help: request help, upload a résumé and book a counselor time.
  5. Texts: opt in, choose topics and quiet hours, then reply R to reschedule or STOP to opt out.
  6. I'm an employer: request hiring help.
  7. Use ES for Spanish, A+ for larger text and ◐ for high contrast.

The same journeys run as a progressive web app linked from workplace.org for people who don't install apps. A standalone full-screen version is at app.html.
