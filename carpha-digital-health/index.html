    How it works

    1. The assistant searches only the console's own library, readiness scores and exchange logs.
    2. Every answer cites the exact library page or data view it used. Click a citation to open it.
    3. If nothing in the sources answers the question, it says so instead of guessing.
    4. In production this would run inside CARPHA's own tenant with a governed language model; this demo uses client-side rules so it works offline.
