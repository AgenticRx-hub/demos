Priority audiences and journeys

Mobile-first

Every template is designed at 375 px first and then scaled up. Navigation collapses to a three-item bar (Research, Act, Donate) on phones, where most social and email traffic lands.

Modern web practice applied

  • Core Web Vitals budget: LCP < 2.5s
  • Structured data for reports (schema.org)
  • Open Graph cards for social sharing

Platform recommendation and cutover plan (c4)

StepDetail
PlatformWordPress multisite: c4 runs as a separate site in the same install as c3, with its own domain, users, content, theme variant and analytics property. One login for staff, with permissions per site.
MigrateMove splash content and assets; add Campaign, Endorsement and About templates using the shared block library.
Domain and hostingLower DNS TTL 72 hours ahead; stage on the new host; test SSL, forms and donations; switch DNS in a low-traffic window; keep the old host for 7 days as a rollback.
DowntimeTarget under 5 minutes (DNS propagation only).
TrainingOne 60-minute session and a 4-page guide.
Phasingc4 launches first (April 2027) as an early win and a pilot of the shared CMS.

Built so non-technical staff can update both sites. We recommend staying on WordPress, rebuilt with the native block editor and custom TechEquity blocks rather than a page builder or reskin. Below: the editor's view of adding a resource.

Why WordPress (and the alternatives we weighed)

OptionFit
WordPress (block editor, multisite)Recommended Staff already know it; no licence; huge plugin ecosystem; content migrates natively; c3 and c4 stay distinct in one install
WebflowStrong design control, but per-site plans, weaker multi-entity permissions and a harder migration
Headless (Sanity/Next.js)Fast and flexible, but needs a developer for routine changes: too heavy for this team
Editorial workflow: Draft → Review → Publish, with scheduled publishing, revision history and roles (Author, Editor, Comms lead, Admin) on each site.

Goodwill add-ons, included at no additional cost. These five extras come with our proposal to show what we can build and to help TechEquity move faster during the decisive 2027–2030 window.

Included · no cost

1. State policy tracker

A filterable map and list of bills TechEquity is working on across states, with status, next hearing and a link to act. Staff update it in the CMS.

Included · no cost

2. "Ask TechEquity" research assistant

Answers questions only from TechEquity's own published research and shows citations, so reporters, staffers and advocates can find the right report fast. It is self-hosted, so no queries go to ad-tech or external model training.

Q: What can states do about rent-setting algorithms?
A (sample): Three levers appear in our research: disclosure requirements, limits on using non-public competitor data, and enforcement funding for the attorney general. Sources: [Sample field guide, p.4], [Sample testimony, 2026]
Included · no cost

3. Policymaker briefing-kit builder

Staff pick a state and an issue, and the site assembles a one-page PDF brief from the hub: summary, key data, related bills and contacts. It's ready for a legislative meeting in minutes.

Included · no cost

4. Press room and expert finder

Press releases, statements, media kit, brand assets and expert bios by topic, with a one-click request to the communications team.

Included · no cost

5. Monthly impact one-pager for funders and the board

An automatic aggregate summary of resource downloads, actions taken, sign-ons, newsletter growth and press mentions, ready for board packets and grant reports.
