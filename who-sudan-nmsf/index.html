    How it works

    1. Answers come only from this assessment's scores, scorecards, stock data and evidence documents.
    2. Every answer cites the finding, data view or evidence page it used. Click a citation to open it.
    3. If the evidence does not answer the question, the assistant says so.
    4. For the real assignment the assistant would run in a WHO-approved environment, with no NMSF data leaving it. This demo runs client-side rules only.
